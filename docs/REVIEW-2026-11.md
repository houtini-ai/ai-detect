This is the review that the `rebuild-2026-11` branch works from. Each defect has an ID (D1...) so commits and tests can point back at it. What the branch did about each one is recorded in the "Review defects" table at the end of `docs/FEATURES.md`.

## 1. Architecture as found

```
detect.py                 shim -> ai_detect.cli.main
ai_detect/
  __init__.py             public API: classify_text, get_detector, diagnose_sentence, MODELS, DEFAULT_MODEL
  patterns.py   (242)     pure Python: sentence splitter, 8 regex pattern families, SDSL metric
  detector.py   (440)     MODELS dict, two backend classes, cache, classify_text()
  cli.py        (156)     argparse CLI, text renderer
  server.py     (357)     FastMCP stdio server, 5 tools, background preload thread
scripts/check_env.py      environment doctor
scripts/strip_html.py     one-off WordPress HTML stripper
tests/test_patterns.py    12 tests, pattern layer only
```

Flow: `classify_text(text)` splits into sentences, skips those under 5 words, sends the rest to `backend.score(list[str]) -> list[float]`, attaches `diagnose_sentence()` findings to each, and returns one dict. The CLI prints it; the MCP server trims it to flagged sentences.

## 2. What is good and should be kept

- **The backend contract is small and right**: `score(sentences) -> list of P(AI)`. Everything above it is model-agnostic. The rebuild keeps this contract.
- **The MCP startup design is careful and correct.** Heavy imports happen once, in one dedicated thread; the `initialize` handshake returns at once; every blocking tool is `async` and offloads through `anyio.to_thread`; a stalled download surfaces as a timeout error. The comments explain the deadlock each choice avoids. None of this needed rework.
- **Per-key construction locks** stop two concurrent first calls loading the same 1.7 GB model twice.
- **The pattern layer has no ML dependency**, so its tests run anywhere with no download.
- `verdict()` is a single source of truth; the Windows UTF-8 stdout fix is real and explained.
- `.gitignore` already excludes weights, secrets and drafts.

## 5. Prioritised plan

1. **Make it installable again (D1, D2, D4, D5).** Support both MCP SDK lines with an import fallback, pin `mcp>=1.10,<3`, raise the Python floor to 3.11, single-source the version.
2. **A real model registry (D9, D10, D14, D3).** One frozen record per model: repo, files, loader kind, licence, RAID rank with source and date, normaliser, runtime requirement. Backends take a spec; nothing else names a model. Missing optional runtimes raise one clear, typed error.
3. **Evaluate the candidates on this machine and add the ones that run (D8, D11).** Measured numbers in `docs/MODEL-EVAL-2026-11.md`. The default stays `desklib` until its owner decides otherwise.
4. **Fix text handling (D15 to D22).** Block-aware splitting, abbreviation guard, markdown stripping, inflection-aware patterns with UK and US spellings, typographic normalisation. Add a document-level score beside the per-sentence ones (D11).
5. **Fix the CLI and MCP edges (D23 to D29)** without renaming anything.
6. **Tests first for all new behaviour (D31)**, with a fake backend so the suite needs no download.
7. Then the new surface: URL input, ensemble, page-level tells, local web UI, batch, history, export.
